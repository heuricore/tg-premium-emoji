# tge Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the skeleton of tg-premium-emoji: a cross-platform `tge` binary that builds a custom emoji pack from the Bot API, renders preview sheets, takes labels, searches and prints snippets; `install.py`; a release pipeline; the `guide`, `pack-build` and `emoji-design` skills; and the built-in `tgiosicons` pack.

**Architecture:** One Rust crate (`crates/tge`, binary plus library for tests) with vendored rlottie compiled by the `cc` crate and a pure-Rust VP9 path for webm. Data lives in JSON catalogs whose schemas are generated from the Rust types. The repository root is the Claude Code plugin; the binary is installed per version by `scripts/install.py` from GitHub Releases, with the built-in catalog shipped next to it.

**Tech Stack:** Rust (edition 2024, `rust-version = "1.89"` for `std::fs::File::lock`), clap 4, serde/serde_json, schemars 1, jsonschema (default features off), thiserror 2, ureq 3 (rustls), flate2, png 0.18, image-webp, vp9dec `=0.1.1`, cc (build). Dev: assert_cmd, predicates, tempfile, tiny_http. Python 3.8+ stdlib for `install.py`, pytest for its tests. Task (Taskfile), GitHub Actions, cargo-zigbuild for linux-arm64.

**Spec:** `docs/superpowers/specs/2026-11-01-tg-premium-emoji-design.md`. Read it before any task; section numbers below refer to it. The render spike lives in `../tge-check/` next to this repository (also `heuricore/tge-check` on GitHub); Tasks 9, 10 and 18 port its code. Paths below written `tge-check/...` are relative to that folder.

## Global Constraints

- Every repository artifact is in English (code, comments, docs, skills, commit messages).
- Commits only after the user has explicitly allowed them for this session; ask once before Task 1. Never push or tag without asking at that moment.
- Edit files with editor tools; no `sed -i`, heredocs or `echo >` into files. Run Python as `uv run python ...` for development (tests: `uv run --with pytest pytest ...`); `install.py` itself must also run with plain `python`.
- After each task run `task check`; it must pass before the task counts as done.
- Targets: `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu` (cargo-zigbuild), `x86_64-pc-windows-msvc`, `aarch64-apple-darwin`, `x86_64-apple-darwin`. The binary depends only on the system libc.
- State root: `TG_PREMIUM_EMOJI_HOME`, default `<home>/.tg-premium-emoji`. Layout per spec 5.4 (`config.json` only from Phase 2): `catalogs/local/`, `cache/src/`, `cache/inspect/`, `bin/<version>/`, `bin/latest`.
- Every data file carries `"schema_version": 1`; unknown fields are rejected.
- Emoji `id`: digit string `^[0-9]{1,20}$`. `name` ≤ 64 chars, `description` ≤ 300, ≤ 24 tags of ≤ 40 chars, ≤ 200 emoji per pack. File limits on load: `pack.json` ≤ 2 MiB, PNG ≤ 4 MiB.
- Enums (serialized lowercase / snake_case): `format` static|tgs|webm; `confidence` high|medium|low (or null = not labeled); `by` agent|human; `fits` text|heading|list_item|button|status|divider.
- Preview layout (fixed for v1): cell 144 px, icon 128 px centred, label strip 24 px under the icon, 5 columns, 20 cells per sheet, background `#1E2127`, digits `#E6E6E6`; sheet file `<short_name>_<page>.png`, page from 1.
- BOT_TOKEN only from the environment; never printed, logged or stored; every HTTP error passes through `redact`. Bot API base URL overridable only through `TGE_BOT_API_BASE` (tests).
- Exit codes: 0 ok, 1 runtime error, 2 usage error, 3 validation issues found. Every command accepts the global `--json`; with `--json`, stdout carries exactly one JSON document, errors as `{"error": "<message>"}`.
- rlottie source: `desktop-app/rlottie` at commit `cbfdcdd2830b4beba53e64e72c11cb0328a720a9`; no cmake, no bindgen, no network at build time.

## Review Focus

1. A rescan where Telegram reordered the set: labels must follow `id`, not `n` (Task 13 test `reorder_keeps_labels_by_id`).
2. A pack name typed in another case (`TgIOSicons` vs `tgiosicons`): one pack, one folder, no duplicate (Task 4 test `pack_lookup_is_case_insensitive`, Task 15 test `rebuild_with_other_case_updates_same_pack`).
3. A network failure halfway through `pack build`: `pack.json` and previews stay untouched, already downloaded sources stay cached, a rerun resumes (Task 15 test `failed_download_writes_nothing`).
4. One source that rlottie or the webm reader cannot decode: the build finishes, that emoji gets an empty cell and `frame_suspect: true` (Task 15 test `undecodable_source_is_suspect_not_fatal`).
5. A search query with no searchable words (`"!!!"`, `""`): usage error with a clear message, no panic (Task 8 test `find_rejects_query_without_words`).
